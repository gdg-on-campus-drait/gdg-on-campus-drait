# Contributing

Thank you for your interest in contributing to GDG on Campus – Dr. AIT projects!

1. Explore the repository and read its README.
2. Check open issues and choose one to work on.
3. Fork the repository and create a feature branch.
4. Make focused changes and test them.
5. Open a pull request with a clear description.
6. Respond to review feedback respectfully.

Please follow the contribution instructions in each project's repository. If you're unsure where to start, look for issues labelled `good first issue` or `help wanted`.
